# GitHub Copilot Advanced: entregas com contexto

_Investigue um problema, decida o que delegar ao Copilot e sustente a entrega com evidências, do diagnóstico à pull request._

Na **Luma Gallery**, você vai ampliar o catálogo de tags, criar um autocomplete acessível por teclado e adicionar testes de regressão. O foco é decidir **o que delegar ao Copilot, que contexto fornecer e como validar o resultado**.

- **Para quem é:** pessoas que já usam Copilot Chat, Git e pull requests e têm noções de TypeScript e React.
- **Pré-requisitos:** acesso ao Copilot, permissão para criar Codespaces e executar Actions.


São **60 minutos de atividades** para Actions e uma correção simples. A estimativa pressupõe Codespace e issue prontos; não é uma duração comprovada com uma turma.

A [extensão de Spaces, MCP e coding agent](.github/steps/x-extension.md) é uma demonstração opcional do facilitador durante a apresentação. Não é uma sétima etapa. Ao final, use a [revisão do exercício](.github/steps/x-review.md) para retomar as decisões.

## Inicie o exercício

1. Use o botão abaixo para criar **uma cópia do template**, não um fork, na sua conta. Prefira um repositório público.
2. Aguarde o workflow **Passo 0** criar a issue do exercício e siga as instruções por lá.
3. Abra o Codespace antes da prática. O uso está sujeito à sua franquia e cobrança.

<summary>Está com dificuldades? 🤷</summary><br/>

- Se a issue não aparecer após alguns minutos, confira **Actions > Passo 0** e verifique se Actions e issues estão habilitados no repositório copiado.
- Se uma execução falhar, leia o erro. Corrija falhas de validação antes de publicar novamente; reexecute apenas em caso de falha temporária.
- Se o problema persistir, abra uma [issue no repositório original](https://github.com/dev-pods/engineering-context-with-github-copilot/issues/new) com a descrição do erro e o link da execução.
